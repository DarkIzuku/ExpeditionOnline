EXPEDITIONONLINE EXPLORATION SERVER
===================================

Double-click Start-Server.bat and keep its window open.
Windows may ask for firewall access: allow Private networks only.
Give the other players your LAN or trusted-VPN IP address.

Run ExpeditionOnlineSelfTest.exe while the server is open to verify late join,
zone changes, reconnect, timeout and malformed-client isolation on this PC.

This release has no authentication or encryption. Use LAN or a trusted VPN.
Do not expose TCP port 7777 directly to the public Internet.

Logs: ExpeditionOnlineServer.log
