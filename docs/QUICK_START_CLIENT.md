# ExpeditionOnline client: quick start

1. Install the compatible official UE4SS build listed in `UE4SS_BUILD_REVISION.txt` in Clair Obscur's `Sandfall/Binaries/Win64` folder.
2. Extract `ExpeditionOnline-Client-Windows-x64.zip`, then double-click `Install-ExpeditionOnline.bat`.
3. Enter your player name and the host's LAN or trusted-VPN IP address.
4. Open Clair Obscur, load a save and enter exploration mode.
5. Both players must be in the same exact zone to see each other; run `Configure-ExpeditionOnline.bat` or Doctor if needed.

UE4SS is an explicit dependency and is not bundled. The installer never downloads an executable and never deletes or changes other mods.

Logs:

- `Sandfall/Binaries/Win64/ue4ss/Mods/ExpeditionOnline/ExpeditionOnline.log`
- `Sandfall/Binaries/Win64/UE4SS.log`
