# ExpeditionOnline host: quick start

1. Extract `ExpeditionOnline-Host-Windows-x64.zip` to a normal folder.
2. Double-click `Start-Server.bat` and keep the window open.
3. If Windows asks, allow firewall access on **Private networks** only.
4. Give the other player your LAN or trusted-VPN IP address.
5. Optionally double-click `ExpeditionOnlineSelfTest.exe` while the server is open; success ends with `SELF_TEST PASS`.

The default TCP port is `7777`. This MVP has no authentication or encryption: use a LAN or trusted VPN and do not expose the port directly to the public Internet.
